# 💄 LUMIÈRE Kozmetik Platformu

**LUMIÈRE**, modern bir kozmetik markası için geliştirilmiş, müşteri odaklı vitrin sitesi ve kapsamlı bir yönetim panelinden oluşan tam kapsamlı bir web platformudur.

Proje; ziyaretçilerin ürünleri inceleyebildiği, marka hakkında bilgi edinebildiği ve iletişim kurabildiği modern bir kullanıcı arayüzünün yanında, tüm içeriklerin kolayca yönetilebildiği güçlü bir admin paneli sunmaktadır.

---

# 📸 Proje Hakkında

Bu proje iki ayrı uygulamadan oluşmaktadır.

```
Project11_LumiereAngular
│
├── frontend   → Angular 21
└── backend    → ASP.NET Core 8 Web API
```

Frontend tarafında modern ve hızlı bir kullanıcı deneyimi hedeflenirken, backend tarafında RESTful API mimarisi kullanılarak tüm veriler merkezi olarak yönetilmektedir.

---

# ✨ Özellikler

## 🌐 Vitrin Sitesi

- Modern ve responsive tasarım
- Banner (Hero) alanı
- Öne çıkan ürünler
- Kategoriye göre filtrelenebilen tüm ürünler sayfası
- Hakkımızda bölümü
- Müşteri yorumları
- İletişim bilgileri
- İletişim formu

---

## ⚙️ Admin Paneli

Yönetim paneli üzerinden aşağıdaki içeriklerin tamamı CRUD işlemleri ile yönetilebilmektedir.

- Ürün Yönetimi
- Kategori Yönetimi
- Hakkımızda Yönetimi
- Öne Çıkan Alan Yönetimi
- Müşteri Yorumları Yönetimi
- İletişim Bilgileri Yönetimi
- Gelen Mesajların Yönetimi

Admin panelinde ayrıca;

- Responsive yönetim ekranları
- Sidebar ve Topbar yapısı
- Tablo tabanlı listeleme ekranları
- Düzenli ve modüler component mimarisi

bulunmaktadır.

---

# 🛠 Kullanılan Teknolojiler

## Frontend

- Angular 21
- TypeScript
- RxJS
- Angular Signals
- Tailwind CSS
- Material Design 3 Renk Sistemi
- Google Fonts
- Material Symbols

---

## Backend

- ASP.NET Core 8 Web API
- Entity Framework Core
- SQLite
- AutoMapper
- Swagger (OpenAPI)

# 🚀 Projenin Amacı

Bu proje, Angular ve ASP.NET Core Web API teknolojilerini kullanarak gerçek hayatta kullanılabilecek kurumsal bir kozmetik markasının web platformunu geliştirmek amacıyla hazırlanmıştır.

Projede modern frontend mimarisi, RESTful API yaklaşımı, katmanlı yapı ve yönetilebilir bir admin paneli birlikte kullanılarak ölçeklenebilir bir yapı oluşturulmuştur.
